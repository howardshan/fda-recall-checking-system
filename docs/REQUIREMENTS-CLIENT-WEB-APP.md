## 二、项目目标（客户可感知价值）

1. **主动守护**：用户登记「药箱」；FDA 召回发布时，通过邮件、站内消息、短信（Web）及 **App 推送** 提醒。
2. **随时核查**：Web 与 App 均可查询召回；Web 完整版含浏览器扫码/拍照；**App 提供原生扫码与相机体验**。
3. **风险分级**：按 FDA Class I / II / III 展示，附官方信息链接。
4. **一致体验**：**同一账户** 登录 Web 与 App，药箱与通知数据同步。
5. **统一交付**：Web 与 App **共用后端与通知架构**，按阶段验收后整体上线运营。

## 三、阶段一 — Web MVP（中期交付）

**目标**：建设可演示、可预发布的 **Web MVP**：FDA 召回数据、用户账户、个人药箱、自动匹配、邮件/站内通知、手动即时查询；并为 App 预留共用 API。

**本阶段不包含**：浏览器扫码/拍照、短信、家庭成员药箱、App 安装包、仿制药 NDC 扩展。

**本阶段工时**：**170 人时**（**USD 17,000**）

### 3.2 阶段一 — MVP 验收清单

- FDA 召回数据可同步，并显示最后更新时间  
- 用户可邮箱注册、Google 登录、管理个人药箱（药品名 + 生产厂家必填）  
- 监控期内（按停药时间策略）召回匹配时收到邮件及站内通知  
- 通知含药品名、厂商、召回等级、原因摘要、FDA 官方链接  
- 用户可通过手动输入 / NDC 进行即时召回查询（**不含**扫码、拍照、短信）  
- 隐私政策、用户协议、Cookie 说明（需客户提供正文）已上线  
- 不提供用药/停药建议  
- MVP 环境稳定运行，数据同步按日执行  
- 后端 API 设计文档可供阶段三 App 对接（架构就绪）
