## 二、项目目标（客户可感知价值）

1. **主动守护**：用户通过**手动填写**将药品登记至「药箱」；FDA 召回发布时，通过邮件、站内消息及短信（完整版）提醒。
2. **随时核查**：用户**手动输入**药品名、生产厂家、NDC、批号等字段，查询是否涉及召回（**不使用**扫码或拍照识别）。
3. **风险分级**：按 FDA Class I / II / III 展示，附官方信息链接。
4. **合规透明**：仅信息聚合与提醒，**不提供**用药或停药建议。
5. **交付节奏**：先 **MVP**，再 **完整 Web 版** 上线运营。

## 三、阶段一 — MVP（中期交付）

**目标**：FDA 召回数据、账户、药箱（手动录入）、自动匹配、邮件/站内通知、手动即时查询。

**本阶段不包含**：条码扫描、拍照/OCR、短信、家庭药箱、移动 App、仿制药 NDC 扩展。

**本阶段工时**：**65 人时**（折合 **USD 6,500**）

### 3.2 阶段一 — MVP 验收清单

- 召回数据可同步并显示更新时间  
- 邮箱 / Google 登录；药箱通过**手动输入**维护（药品名 + 厂商必填）  
- 监控期内匹配召回可收邮件与站内通知  
- 通知含等级、原因、FDA 链接  
- **手动**即时查询（无扫码、无拍照、无短信）  
- 法律页面与 Cookie 说明已上线  
- MVP 环境稳定、同步按日执行
